# 300%的宏观杠杆率对应约420万亿元债务，应如何按贷款与债券口径拆解，社融存量与实体部门债务总量是什么关系？

> **要义**：宏观杠杆率分子是非金融部门债务，NIFD口径2025年末约302.4%，对应约423万亿元。420万亿须区分最大口径本外币贷款（含境外与同业拆放）与社融口径贷款；社融存量442万亿元也不等于债务总量，差异来自股票融资、外债与统计边界。“社融减股票”是高度近似而非恒等式。社融记录全渠道融资结构与信用传导状态；债务刻度由实体部门债务总量承担。

## 分析价值

剥离口径可以避免把境外贷款、对非银机构拆放和金融债误算为实体债务，也避免把社融中的股权融资误当债务。社融记录金融体系向实体输送资金的全面渠道，可用于观察融资结构、信用扩张方向与货币政策传导状态。

## 核心逻辑

**一、杠杆率公式与分子边界**

宏观杠杆率=非金融部门债务/GDP。分子只计需要偿还的债务工具，不含金融部门负债和股权融资。NIFD口径下，2025年末中国宏观杠杆率约302.4%，GDP约140万亿元，对应实体部门债务约423万亿元。

**二、贷款口径的两层拆解**

| 口径 | 2025年末余额 | 主要构成 | 与实体债务的关系 |
|---|---:|---|---|
| 最大口径本外币贷款 | 275.74万亿元 | 含境内贷款、境外贷款、对非银机构拆放 | 不能直接代入杠杆率分子 |
| 社融口径本外币贷款 | 约269.5万亿元 | 人民币贷款268.4万亿元+外币贷款1.05万亿元 | 剔除境外与同业拆放，接近实体信贷债务 |

两者差额约6万亿元，主要对应境外贷款和对非银行业金融机构贷款。2025年非银贷款全年减少1103亿元，这一块在收缩，但它始终存在于最大口径中，不能与社融口径混用。

**三、债券与非标的口径拆解**

2025年末社融存量442.12万亿元，贷款之外的主要构成包括：

| 项目 | 2025年末余额 | 是否计入实体债务 |
|---|---:|---|
| 政府债券 | 94.92万亿元 | 是 |
| 企业债券 | 34.24万亿元 | 是 |
| 非金融企业境内股票 | 12.2万亿元 | 否（股权融资） |
| 委托贷款 | 11.35万亿元 | 是 |
| 信托贷款 | 4.67万亿元 | 是 |
| 未贴现银行承兑汇票 | 2.15万亿元 | 是 |
| 金融债 | 不在社融统计中 | 否（金融部门负债） |

金融债属于金融部门负债，不计入社融存量，也不进入宏观杠杆率的实体债务分子。将金融债混入实体债务会重复计算金融同业信用扩张。

**四、社融存量与实体债务总量的关系**

实体部门债务总量≈社融存量−非金融企业境内股票融资。442.12万亿元减去12.2万亿元，约430万亿元，与NIFD口径的423万亿元接近。差额主要来自外债、政府债券口径边界及少量统计调整。“社融减股票”是高度近似，不是严格恒等式。

**五、社融存量的观察用途**

社融存量有三个观察用途。其一，它是金融支持实体的综合刻度，覆盖贷款、债券、股票、非标等全渠道融资。其二，它是货币政策传导的监测面：社融增速持续显著高于名义增速，意味着信用扩张推升杠杆；低于名义增速，则意味着信用条件被动收紧。其三，社融与M2的剪刀差可观察资金流向：社融相对M2走阔，通常意味着信用向实体渗透；M2相对社融走阔，则提示资金可能在金融体系内部滞留。社融与其他金融总量指标的相对关系，可以暴露信用扩张在哪个环节发生淤积或漏损。

## 例证

- **2025年社融增量结构**：全年社融增量35.6万亿元，企业债券、政府债券与股票融资合计占比约47%，首次超过贷款，直接融资在增量中的份额上升。
- **杠杆率被动上升**：2025年社融存量增长8.3%，名义GDP增长4.0%，债务扩张趋缓，分母收缩更快，杠杆率被动抬升。
- **最大口径与社融口径的差额**：某月央行披露的新增人民币贷款减去居民、企业和非银贷款后，剩余缺口与当月境外人民币贷款增加额几乎一致，最大口径中包含不进入社融的境外投放。

## 辨析存疑

“社融减股票”是近似口径，不是严格恒等式；政府债券的社融口径与财政口径存在边界差异；外债等调整项量级不大但不可忽略；NIFD与BIS在政府债务和外债处理上也有差异，跨来源比较时需先对齐口径。
