# 中国银行业为什么从“存款立行、贷款即资源”转向“贷款立行、好客户难找”？

> **要义**：1995 年前利率管制压低资金价格、国企软约束和银行政策工具身份共同造成“贷款即资源”；1995 年《商业银行法》确立自负盈亏，1997 年亚洲金融危机暴露巨额坏账，1998 年取消贷款规模指令，银行按风险定价，惜贷出现。

## 核心逻辑

**1995 年前的状态与成因**：

| 要素 | 表现 |
|---|---|
| 利率 | 法定利率，人为压低贷款利率以服务国企 |
| 国企 | 平均负债率 80% 以上，资金利润率 1.85%，净资产收益率约 4.5% |
| 利差 | 一年期贷款基准利率 12.96% 甚至更高，微薄利润难以覆盖利息 |
| 银行 | “专业银行”，按国家计划投放信贷，主要任务是支持建设 |
| 民企与个人 | 资金优先供给国企，只能在资金富余时获得少量高利率贷款，难度极大 |

**“贷款即资源”的传导链条**：贷款利率被压到均衡水平以下 → 资金需求超过供给 → 信贷按计划分配而非按价格分配 → 获得贷款等于获得一块低于市场价格的资金 → 利差本身构成利润 → 争取到贷款就是争取到一块资源。这一链条成立的前提是利率管制与银行不承担风险，两个前提在 1995 年后依次被拆掉。

**1995—1997 年的转折条件**：

1. 1995 年《商业银行法》确立银行“自主经营、自担风险、自负盈亏”的独立法人地位。
2. 1997 年亚洲金融危机暴露银行巨额不良资产，银行体系资本被侵蚀。
3. 1997 年 11 月第一次全国金融工作会议：定向发行 2700 亿元特别国债补充资本金，13939 亿元不良资产剥离给四大资产管理公司。
4. 1998 年央行取消贷款规模指令性计划，实行资产负债比例管理。

**后果**：银行开始像企业一样关心风险与利润，面对大量不良债务转向惜贷、恐贷。1998 年国有商业银行比计划少增贷款 357 亿元。

## 例证

- **国企盈利**：1995 年国企平均负债率 80% 以上，资金利润率 1.85%。
- **惜贷规模**：1998 年国有商业银行比计划少增贷款 357 亿元。
- **注资与剥离**：1997 年金融工作会议确定 2700 亿元特别国债注资、13939 亿元不良资产剥离。

## 辨析存疑

不压制利率的替代措施：人民币适度贬值刺激出口、建立股票债券市场发展直接融资、放开民营与外资银行准入、财政直接注资或允许经营不善的国企破产。对话未给出低息贷款的总量规模与具体利率区间，不编造。
